# Consent-safe interview evidence

This directory is the canonical, consent-safe location for interview-derived evidence. It replaces the former contributor-specific folders; those source folders were removed after these anonymized records were prepared.

## Consent and privacy

- Participants consented on **18 September** to share anonymized summaries for this assignment.
- Records use only participant role categories. Names, employer/client names, contact details, and identifying operational details are omitted.
- These are edited notes/summaries, not verbatim transcripts or independently validated process-mining data.
- Do not infer employer identity from tool names or workflow details, and do not add raw recordings, receipts, or consent messages to the repository.
