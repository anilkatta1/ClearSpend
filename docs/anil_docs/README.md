## Evidence classification

- The process description and feedback were supplied by Anil and edited for clarity.
- The employer is intentionally unnamed; this repository contains no personal or client data.
- The employer-feedback document is a summary, not a verbatim transcript.
- The participant was a finance-team member interviewed on 21 September 2026 and consented to publication with anonymization; the consent channel was not recorded in the supplied notes.
- Additional analysis is explicitly labeled as team interpretation or recommendation.
- This is useful qualitative evidence but does not by itself satisfy the assignment requirement for observations from 3–5 relevant real users.
